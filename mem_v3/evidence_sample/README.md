# Evidence sample

This directory is reserved for small, sanitized evidence examples.

Do not place full dataset caches, checkpoints, API keys, local secrets or machine-specific heavy runtime output here.

A useful evidence bundle may include:

```txt
final status
runtime progress summary
controller events summary
lane decisions
API Light decisions when enabled
hardware snapshot
logs tail
```

Do not fabricate metrics. If a metric was not recorded, mark it as unavailable.
